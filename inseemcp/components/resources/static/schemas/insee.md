# INSEE APi schema

Ce document décrit les variables retournées par l’API Sirene pour les unités légales et les établissements. Il est à jour pour la version 3.11 de l’API.

## Legal Unit

| Variable                                      | Content                                                                                                                                                   | Comment                                                                                                                                       |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| siren                                         | Numéro Siren de l'entreprise                                                                                                                             | Toujours renseigné                                                                                                                           |
| statutDiffusionUniteLegale                    | Statut de diffusion de l’unité légale                                                                                                                  | O ou P (ou M prochainement)                                                                                                                   |
| **unitePurgeeUniteLegale**              | True si l'unité est une unité purgée                                                                                                                   | Pour les unités non purgées, variable non présente dans la réponse                                                                        |
| dateCreationUniteLegale                       | Date de création de l'unité légale                                                                                                                     | Format AAAA-MM-JJ                                                                                                                             |
| sigleUniteLegale                              | Sigle de l’unité légale                                                                                                                                | [ND] si diffusion partielle                                                                                                                   |
| sexeUniteLegale                               | Sexe pour les personnes physiques                                                                                                                         | M, F*Null* pour les personnes morales[ND] si diffusion partielle                                                                            |
| prenom1UniteLegale                            | Premier prénom pour les personnes physiques                                                                                                              | *Null* pour les personnes morales[ND] si diffusion partielle                                                                                |
| prenom2UniteLegale                            | Deuxième prénom pour les personnes physiques                                                                                                            | *Null* pour les personnes morales[ND] si diffusion partielle                                                                                |
| prenom3UniteLegale                            | Troisième prénom pour les personnes physiques                                                                                                           | *Null* pour les personnes morales[ND] si diffusion partielle                                                                                |
| prenom4UniteLegale                            | Quatrième prénom pour les personnes physiques                                                                                                           | *Null* pour les personnes morales[ND] si diffusion partielle                                                                                |
| prenomUsuelUniteLegale                        | Prénom usuel pour la personne physique                                                                                                                   | *Null* pour les personnes morales[ND] si diffusion partielle                                                                                |
| pseudonymeUniteLegale                         | Pseudonyme pour les personnes physiques                                                                                                                   | *Null* pour les personnes morales[ND] si diffusion partielle                                                                                |
| identifiantAssociationUniteLegale             | Numéro au Répertoire National des Associations ou autre répertoire d'association                                                                       |                                                                                                                                               |
| trancheEffectifsUniteLegale                   | Tranche d’effectif salarié de l’unité légale                                                                                                         | Valeur de la tranche d’effectif si connue, sinon NN                                                                                          |
| anneeEffectifsUniteLegale                     | Année de la tranche d’effectif salarié de l’unité légale                                                                                            | Uniquement si trancheEffectifsUniteLegale est renseignée, sinon*null*                                                                      |
| dateDernierTraitementUniteLegale              | Date de la dernière mise à jour effectuée au répertoire Sirene sur le Siren concerné                                                                 | Format AAAA-MM-JJTHH:MM:SS.MMM                                                                                                                |
| nombrePeriodesUniteLegale                     | Nombre de périodes dans la vie de l’unité légale                                                                                                      |                                                                                                                                               |
| categorieEntreprise                           | Catégorie à laquelle appartient l’entreprise : PME = petite ou moyenne entreprise ; ETI = entreprise de taille intermédiaire ; GE = grande entreprise |                                                                                                                                               |
| anneeCategorieEntreprise                      | Année de validité de la catégorie d’entreprise                                                                                                        |                                                                                                                                               |
| dateFin                                       | Date de fin de la période                                                                                                                                | *Null* pour la dernière périodeFormat AAAA-MM-JJ                                                                                          |
| dateDebut                                     | Date de début de la période                                                                                                                             | Format AAAA-MM-JJ                                                                                                                             |
| etatAdministratifUniteLegale                  | État de l'entreprise pendant la période : A = entreprise active ; C = entreprise cessée                                                                |                                                                                                                                               |
| changementEtatAdministratifUniteLegale        | Indicatrice de changement d'état par rapport à la période précédente                                                                                 |                                                                                                                                               |
| nomUniteLegale                                | Nom de naissance pour les personnes physiques pour la période                                                                                            | *Null* pour les personnes morales[ND] si diffusion partielle                                                                                |
| changementNomUniteLegale                      | Indicatrice de changement du nom de naissance par rapport à la période précédente                                                                     |                                                                                                                                               |
| nomUsageUniteLegale                           | Nom d’usage pour les personnes physiques si celui-ci existe                                                                                             | *Null* pour les personnes morales[ND] si diffusion partielle                                                                                |
| changementNomUsageUniteLegale                 | Indicatrice de changement du nom d’usage par rapport à la période précédente                                                                         |                                                                                                                                               |
| denominationUniteLegale                       | Raison sociale pour les personnes morales                                                                                                                 | *Null* pour les personnes physiques[ND] si diffusion partielle                                                                              |
| changementDenominationUniteLegale             | Indicatrice de changement de la dénomination par rapport à la période précédente                                                                     |                                                                                                                                               |
| denominationUsuelle1UniteLegale               | Premier nom sous lequel l’entreprise est connue du public                                                                                                | [ND] si diffusion partielle                                                                                                                   |
| denominationUsuelle2UniteLegale               | Deuxième nom sous lequel l’entreprise est connue du public                                                                                              | [ND] si diffusion partielle                                                                                                                   |
| denominationUsuelle3UniteLegale               | Troisième nom sous lequel l’entreprise est connue du public                                                                                             | [ND] si diffusion partielle                                                                                                                   |
| changementDenominationUsuelleUniteLegale      | Indicatrice de changement de la dénomination usuelle (ensemble des 3 dénominations usuelles) par rapport à la période précédente                    |                                                                                                                                               |
| categorieJuridiqueUniteLegale                 | Catégorie juridique de l'entreprise                                                                                                                      | =1000 pour les personnes physiques                                                                                                            |
| changementCategorieJuridiqueUniteLegale       | Indicatrice de changement de la catégorie juridique par rapport à la période précédente                                                              |                                                                                                                                               |
| activitePrincipaleUniteLegale                 | Activité principale de l'entreprise pendant la période                                                                                                  | APE codifiée selon la nomenclature d'Activités Française (NAF) depuis 1993 et la nomenclature d'activités et de produits (NAP) auparavant |
| nomenclatureActivitePrincipaleUniteLegale     | Nomenclature de l’activité                                                                                                                              | Indique la nomenclature utilisée pour activitePrincipaleUniteLegale                                                                          |
| changementActivitePrincipaleUniteLegale       | Indicatrice de changement de l'activité principale par rapport à la période précédente                                                               |                                                                                                                                               |
| nicSiegeUniteLegale                           | Identifiant du siège pour la période                                                                                                                    | Le Siret du siège est obtenu en concaténant le Siren et le Nic                                                                              |
| changementNicSiegeUniteLegale                 | Indicatrice de changement de siège par rapport à la période précédente                                                                               |                                                                                                                                               |
| economieSocialeSolidaireUniteLegale           | Appartenance de l’unité légale au champ de l’économie sociale et solidaire (ESS)                                                                    | O, N ou*null*                                                                                                                               |
| changementEconomieSocialeSolidaireUniteLegale | Indicatrice de changement de l’appartenance à l’ESS par rapport à la période précédente                                                            |                                                                                                                                               |
| societeMissionUniteLegale                     | Appartenance de l’unité légale au champ des sociétés à mission                                                                                      | O, N ou*null*                                                                                                                               |
| changementSocieteMissionUniteLegale           | Indicatrice de changement de l'appartenance au champ des sociétés à mission par rapport à la période précédente                                   |                                                                                                                                               |
| caractereEmployeurUniteLegale                 | Toujours*null*                                                                                                                                          | La variable n'est plus gérée                                                                                                                |
| changementCaractereEmployeurUniteLegale       | Indicatrice de changement du caractère employeur par rapport à la période précédente                                                                 | La variable n'est plus gérée                                                                                                                |
