# SIREN

## Definition

A SIREN is a 9-digit identifier associated with a French legal unit.

## Format

A SIREN normally contains 9 digits.

Example:

123456789

## Relationship to SIRET

A SIRET identifies an establishment.

The first 9 digits of a SIRET correspond to the SIREN of its legal unit.

Therefore:

SIREN → legal unit

SIRET → establishment

## Tool selection

Use a SIREN lookup tool when the user provides a specific SIREN.

Use an establishment search when the user wants to find establishments belonging to a SIREN.
