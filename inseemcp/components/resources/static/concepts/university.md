# University

A **[university](https://en.wikipedia.org/wiki/University)** is an institution of tertiary education and research which awards academic degrees in several academic disciplines.

## Relationship to legal unit

University (e.g. Université de Lille) → SIREN → Legal Unit

University Antenna (e.g. Université Lille 1) → SIRET → Establishment

## Tool selection

When the user asks for a SIREN, use the `get_university_by_siren`lookup tool to add additional information and context to the original search.

In the case of a SIRET, use the `get_university_by_siret`.

Always start by searching the INSEE database first before using either of these tools.
